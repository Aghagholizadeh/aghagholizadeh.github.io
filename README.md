# SEHM Lab website

Website for the Structural Engineering and Health Monitoring Laboratory at Loyola Marymount University.

The site is built with Jekyll and the [al-folio](https://github.com/alshedivat/al-folio) theme ecosystem. GitHub Actions builds and publishes the `master` branch to GitHub Pages.

## Local preview

```sh
bundle install
bundle exec jekyll serve
```

Then open `http://127.0.0.1:4000/`.

## Content

- Main pages: `_pages/`
- News posts: `_posts/`
- Selected publications: `_bibliography/papers.bib`
- Publication PDFs: `assets/pdf/`
- Site images: `assets/img/sehm/`
